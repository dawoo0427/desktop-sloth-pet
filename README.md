# 🦥 나무늘보 데스크탑 펫 (Desktop Sloth Pet)

바탕화면에서 같이 노는 귀여운 픽셀 나무늘보예요. 마우스에 반응하고, 눈을 깜빡이고, **클릭하면 구글 AI 비서**가 되어 질문·문서·엑셀까지 도와줘요!

## ⬇️ 다운로드 (가장 쉬운 방법)

1. **[➡️ 최신 버전 다운로드 (Releases)](../../releases/latest)** 페이지로 이동
2. `DesktopSlothPet.exe` 를 받아서 **더블클릭**하면 끝!

> ⚠️ 처음 실행할 때 파란색 **"Windows의 PC 보호" 경고**가 뜰 수 있어요.
> → **추가 정보** → **실행** 을 누르면 됩니다. (서명되지 않은 개인 제작 앱이라 그래요)
> 첫 실행은 압축을 푸느라 몇 초 걸릴 수 있어요.

## 🎮 조작법

| 동작 | 설명 |
|---|---|
| **F2** | 마우스 따라오기 **ON/OFF** 토글 (모니터 2·3번까지!) |
| **F3** | 제자리에 멈추기 **ON/OFF** 토글 |
| **F4** | 현재 위치 **날씨** 알려주기 |
| **F9** | **거대 나무늘보 소환** (우측 하단에 누운 모습으로 등장, 여러 번 누르면 여러 마리!) |
| **F10** | 거대 나무늘보 **눕힘 ↔ 일어서기** 토글 |
| **클릭** | 배 아래 **입력창**이 떠요 → **구글 AI 비서**에게 질문/문서/엑셀 요청 (아래 [🤖 구글 AI 비서](#-구글-ai-비서-질문문서엑셀) 참고) |
| **드래그** | 원하는 곳으로 옮기기 (입력창도 같이 따라와요) |
| **우클릭** | 메뉴 (단축키 안내 / Gemini 키 설정 / 종료 등) |

> 단축키는 평소 거의 안 쓰는 **F2·F3·F4·F9·F10** 으로 통일했어요. (우클릭 메뉴에서도 볼 수 있어요)
> 나무늘보는 항상 **다른 창보다 위에** 떠 있어서, 브라우저·프로그램 새 창을 열어도 뒤로 숨지 않아요.
> 평소(따라오기 OFF)엔 화면을 랜덤으로 느긋하게 배회해요. **F2**를 누르면 마우스를 따라와요.
> 거대 나무늘보는 **누우면** 세근세근 숨 쉬며 쿨쿨 자고(💤 Zzz), **일어서면** 일반 나무늘보처럼 깜빡이며 돌아다니고 응원 말풍선을 건네요. 모든 모션은 부드러운 60FPS!

힘이 나는 좋은 말만 말풍선으로 건네줘요 💬💚

## ✨ 기능

- **여러 번 실행**해도 나무늘보들이 서로 겹치지 않고 떨어져 배치/이동
- **멀티모니터** 지원 — F2 누르면 다른 모니터까지 따라옴
- 기분별 애니메이션 클립(눈깜빡 / 통통 / 놀람 / 갸웃), 각 60프레임
- 응원 메시지 말풍선(자동 줄바꿈으로 안 잘림)
- 둥실둥실 떠다니고 / 배경 투명(항상 위)
- **현재 위치 날씨** 알려주기 (실행 시 자동 + `F4`)
- **항상 최상단** — 브라우저·프로그램 새 창을 열어도 뒤로 숨지 않음
- **구글 AI 비서** — 클릭해서 질문/문서/엑셀 만들기 (아래 참고)

## 🤖 구글 AI 비서 (질문·문서·엑셀)

나무늘보를 **클릭**하면 배 아래에 입력창이 떠요. 무엇이든 입력하면 **구글 AI(Gemini)** 가 맥락을 파악해서:

| 입력 예시 | 결과 |
|---|---|
| `나무늘보는 왜 느려?` | 답을 머리 위 **말풍선**으로 |
| `재택근무 장단점 보고서 써줘` | **.txt 문서** 생성 |
| `주간 운동 계획을 엑셀표로 만들어줘` | **.xlsx 엑셀 파일** 생성 |

> 만든 문서/엑셀은 `다운로드\나무늘보작업물` 폴더에 저장되고 **자동으로 열려요.**

### 🔑 구글 AI(Gemini) API 키 연동법 (무료)

이 기능을 쓰려면 **무료 Gemini API 키**가 필요해요. (키가 없으면 안내 문구만 떠요.)

1. **[Google AI Studio — API 키 만들기](https://aistudio.google.com/app/apikey)** 접속 → 구글 계정으로 로그인
2. **`Create API key`(API 키 만들기)** 클릭 → 키 생성 → **키 전체를 복사** (키 값은 이때 한 번만 보여요)
   - 무료 등급이라 **신용카드/결제 등록 없이** 바로 발급돼요.
3. 나무늘보 **우클릭 → `Gemini 키 설정(구글 AI)`** → 복사한 키를 붙여넣고 **저장**
4. 끝! 이제 나무늘보를 클릭해서 무엇이든 물어보거나 문서·엑셀을 부탁하세요.

> 🔒 키는 **내 PC에만** 저장돼요 (`%APPDATA%\DesktopSlothPet\gemini_key.txt`). exe·깃허브에는 들어있지 않아요.
> 환경변수 `GEMINI_API_KEY` 로 설정해도 됩니다.

> 💡 텍스트(질문·문서·엑셀)는 무료 등급으로 충분히 쓸 수 있어요. 가끔 `무료 한도 초과` 안내가 뜨면 잠시 후 다시 시도하면 돼요.

## 🛠️ 직접 빌드하기 (개발자용)

> 캐릭터나 모션을 바꾼 뒤 직접 exe를 만들고 싶을 때

필요: **Windows + Python 3.10+**

```powershell
# 1) (선택) 캐릭터/모션 바꿨다면 프레임 다시 생성
python build_frames.py

# 2) 단일 exe로 빌드  ->  dist\나무늘보펫.exe
./build_exe.ps1
```

### 캐릭터 교체
`나무늘보.png`(투명 배경 PNG)를 다른 그림으로 바꾸고 `python build_frames.py` 를 실행하면 됩니다.
눈 위치는 자동 검출되고, 창 크기는 프레임에서 자동 계산돼요.

### 구성
| 파일 | 설명 |
|---|---|
| `pet.py` | 실행 본체 (tkinter, 외부 패키지 불필요) |
| `build_frames.py` | 원본 그림 → 애니메이션 프레임 생성 (Pillow 필요) |
| `build_exe.ps1` | 단일 exe 빌드 스크립트 (PyInstaller) |
| `frames/` | 미리 렌더된 클립 프레임 |
| `나무늘보.png` | 원본 캐릭터 그림 |
